# E-commerce | Catálogo y carrito de compras

Aplicación web de comercio electrónico desarrollada con HTML5, CSS3 y JavaScript puro (Vanilla JavaScript), sin utilizar frameworks.

El proyecto busca aplicar conceptos de desarrollo frontend, manipulación del DOM, consumo de APIs, almacenamiento local y diseño responsivo
e implementa un catálogo de productos interactivo, funcionalidades de búsqueda y ordenamiento, paginación y un carrito de compras con almacenamiento local.

## Características principales

- **Catálogo de productos:** visualización dinámica de productos obtenidos desde una API externa.
- **Búsqueda:** permite localizar productos dentro del catálogo.
- **Ordenamiento:** opciones para organizar los productos según distintos criterios.
- **Paginación:** distribución de los productos en distintas páginas.
- **Carrito de compras:** permite agregar, eliminar y modificar las cantidades de los productos.
- **Almacenamiento local:** persistencia del carrito mediante `localStorage`.
- **Diseño responsivo:** adaptación de la interfaz a dispositivos móviles, tablets y computadores.
- **Interfaz interactiva:** componentes dinámicos desarrollados con JavaScript.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript puro (Vanilla JavaScript)
- API de [DummyJSON](https://dummyjson.com/)
- LocalStorage
- Visual Studio Code

## Diseño responsivo

La interfaz se adapta a diferentes tamaños de pantalla:

- Dispositivos móviles.
- Tablets.
- Computadores de escritorio.

Se utilizaron Media Queries, Flexbox y CSS Grid para organizar y adaptar los componentes de la interfaz.

## Ejecución del proyecto

1. Clonar el repositorio:

   ```bash
   git clone URL_DEL_REPOSITORIO
   ```

2. Abrir la carpeta del proyecto en Visual Studio Code.

3. Ejecutar el archivo `index.html` utilizando Live Server o un servidor local compatible.
